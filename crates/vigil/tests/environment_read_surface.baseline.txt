# Frozen environment-read inventory for every production crate's src/:
# crates/vigil/src, crates/vigil-ha/src, crates/vigil-bin/src.
#
# One record per line: file|function|variable
#   file     - the crate name, then a path relative to that crate's src/
#              (e.g. "vigil/config.rs", "vigil-ha/ha_discovery.rs")
#   function - the enclosing function or item name (never a line number)
#   variable - the literal environment variable name, or the literal token
#              <dynamic> when the call computes the name from a parameter
#              instead of a string literal (recorded honestly rather than
#              guessed at)
#
# This file may only shrink as reads are migrated to declared settings
# (add-on options, CLI flags, config file fields). It must never grow to
# make room for a new ad-hoc read; environment_read_surface.rs enforces
# both directions. vigil-ha and vigil-bin hold zero entries today — that is
# the correct, observed starting point, not an oversight.
